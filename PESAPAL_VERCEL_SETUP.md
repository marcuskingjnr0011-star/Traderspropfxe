# TradersProp — Pesapal setup

The payment dashboard is wired to Pesapal API 3.0. The server keeps the Pesapal credentials private and creates the checkout from Vercel serverless functions.

## Vercel environment variables

Set these in the TradersProp Vercel project:

- `PESAPAL_ENV` = `sandbox` for testing, then `live` for production
- `PESAPAL_CONSUMER_KEY` = your Pesapal consumer key
- `PESAPAL_CONSUMER_SECRET` = your Pesapal consumer secret
- `PESAPAL_NOTIFICATION_ID` = the IPN notification ID generated by Pesapal
- `PESAPAL_CALLBACK_URL` = `https://YOUR-DOMAIN/?payment=pesapal-return`
- `PESAPAL_CANCEL_URL` = `https://YOUR-DOMAIN/?payment=pesapal-cancelled` (optional)

The existing Supabase server variables remain required:

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`

## IPN URL

Register this publicly reachable URL with Pesapal:

`https://YOUR-DOMAIN/api/v1/payments/pesapal/ipn`

Use the notification ID returned by Pesapal as `PESAPAL_NOTIFICATION_ID`.

## Flow

1. TradersProp calls `/api/v1/payments/pesapal/checkout`.
2. The server authenticates with Pesapal API 3.0 and submits the order.
3. The browser is redirected to the Pesapal payment page.
4. Pesapal redirects the customer to the callback URL.
5. Pesapal also calls the IPN endpoint on status changes.
6. TradersProp queries `GetTransactionStatus` and stores the verified result in Supabase `payment_orders`.

Do not put the consumer secret in `index.html` or any browser-side code.
